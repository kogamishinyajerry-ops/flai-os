# SF-1 台架试验安全规范（合成演示版，非真实规范）

- **SF-1.1** 本规范适用于全部台架试验的安全管理，大纲的安全性审查以本规范为依据。
- **SF-2.1** 每份试验大纲必须**明确指定试验安全员**（记名到人），并列明安全员具有不经请示直接中止试验的权限。未指定安全员的大纲不得批准。
- **SF-3.2** 涉及旋转部件或高压管路的试验，大纲的试验准备部分须包含**防护屏障完好性检查**项。
- **SF-4.3** 大纲必须包含**超限中止判据与超限处置流程**：明确哪些通道超限须立即中止、发现超限后的降载/停车步骤、以及超限事件的记录与报告要求。缺少超限处置内容的大纲视为安全要件不全。
- **SF-5.1** 试验前须组织安全交底，大纲中须写明安全交底的安排，交底会议记录随试验档案归档。
- **SF-5.2** 夜间连续运转试验须安排双岗值守（本条不适用于日间单班试验）。
