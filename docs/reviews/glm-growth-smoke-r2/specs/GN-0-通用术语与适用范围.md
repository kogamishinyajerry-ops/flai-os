# GN-0 台架试验规范体系 · 通用术语与适用范围（合成演示版，非真实规范）

- **GN-1.1** 本规范体系适用于部门台架性能类试验的大纲编制、数据记录、设备标定与安全管理。
- **GN-1.2** 规范体系由五份文件构成：GN-0（本文件）、SF-1 安全规范、DR-1 数据记录规范、OL-1 大纲编制规范、CAL-1 设备标定规范。条款编号全体系唯一。
- **GN-2.1** 术语：**测点**指安装于试验件或台架的单一物理量测量位置；**通道**指测点经采集系统形成的数据序列。
- **GN-2.2** 术语：**超限**指通道实测值越出限值表规定的上限或下限；**工况**指一组保持恒定的试验状态参数组合。
- **GN-2.3** 术语：**大纲**指经批准用于指导一次试验全过程的正式文件。
- **GN-3.1** 各专业规范条款与本文件冲突时，以专业规范为准。
