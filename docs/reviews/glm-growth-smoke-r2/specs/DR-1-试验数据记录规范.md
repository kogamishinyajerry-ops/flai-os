# DR-1 试验数据记录规范（合成演示版，非真实规范）

- **DR-1.1** 本规范规定台架试验数据的采集、记录、备份与归档要求。
- **DR-2.2** 大纲须列明全部测点清单，每个测点至少包含：通道名、量程、单位。清单不全的按大纲要件缺失处理。
- **DR-3.2** 数据采样率要求：**稳态性能测点采样率不得低于 20 Hz**；瞬态过程（起动、加减速、故障模拟）采样率不得低于 200 Hz。低于本条要求的采样配置须在大纲中给出书面偏离论证并经批准。
- **DR-4.1** 试验过程中发现通道数据异常（跳变、断线、漂移）时，应在试验记录中当场登记，不得事后补记。
- **DR-5.1** 试验原始数据须于**试验当日完成双介质备份**（本地存储 + 部门归档服务器各一份），大纲中须写明数据备份的责任人。仅存于单一介质（含个人计算机）不满足本条。
- **DR-5.3** 原始数据保存期限不少于十年，删除须经部门批准。
