# 排版微则（N11 · 2026-07-15）

> 补 UI-DESKTOP-CRAFT / UI-PARADIGM 之外的字排细节。规则少而硬，全部可 grep 验收。

## 1. 数字一律 tabular-nums

**规则**：所有会**变动/对齐/计数**的数字（待签发数、运行数、进度 x/y、token 合计、
文件大小、秒表）必须等宽数字渲染——全局工具类 `.num-token`（App.vue），或对
整块数字元素直接 `font-variant-numeric: tabular-nums`。

**为什么**：比例数字下 `9→10` 会让整行横移一像素级抖动；状态坞/速览这类 2s
轮询区，抖动=视觉噪声=「界面在慌」。等宽数字是 Claude/Codex 桌面工艺的共同
底线细节。

**已覆盖面**（本批审计）：StatusDock 双 pill · StatusCenter 分组计数/样本数/
产物截断数 · WorkbenchSession 进度大数/子行/待签/已召集 · TaskDetail 模型
调用/产物行数/思考秒表（前批已有）。新增计数渲染点一律随手挂 `.num-token`。

## 2. 中西文混排间距

**规则**：中文与拉丁字母/数字相邻时**留一个半角空格**；数字与中文量词之间同样
（「3 个任务」不是「3个任务」）。全角标点两侧不再加空格。已有文案基本遵守，
新文案照此写——不引入 CSS `text-spacing` 类 hack（浏览器支持不齐，人写对
比机器补救便宜）。

**例**：`已召集 · 1 个任务` ✓ ｜ `共 15 件产物` ✓ ｜ `token 合计 1,024` ✓

## 3. 计数与单位不换行拆散

数字与其量词/单位是一个语义原子——模板里写在同一行文本节点，`.num-token`
只包数字本身，不把空格吞进 span（拆散后 flex 容器可能在数字与单位之间断行）。
计数行容器需要换行时用 `flex-wrap` 让整个「数字+单位」原子一起换。
