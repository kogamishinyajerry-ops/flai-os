# ADR-0037：Phase 0A 三条黄金工作流

- 状态：产品方向已接受（委托人在本次设计会话中确认，2026-07-23；不构成组织签发、试点或上线授权）
- 关联：ADR-0005、ADR-0015、ADR-0016、ADR-0027、ADR-0034、ADR-0035、ADR-0036

Phase 0A 面向 5–8 名具名技术验收人员，只把三类完整用户结果作为对外黄金工作流：智能办公助手、CFD 工程助手和会议行动助手。黄金工作流是用户从单一 Composer 提交目标后，由控制内核自动编排有界技能或 Agent 完成并形成 Delivery Bundle 的端到端任务，不等同于一个大而全 Agent，也不以展示 Agent 数量为目标。

智能办公助手负责高频个人内容生产，统一承接报告润色、文档总结、Excel 分析、PPT 材料、规章快查、邮件草拟和基础纪要整理；底层能力必须按文件类型、知识范围和外部影响拆成最小技能。Phase 0A 可生成或修改隔离副本，外部邮件只草拟不发送，规章回答必须携带来源，不能用“办公助手”名义取得永久 Full Access 或直接控制 Office GUI。

CFD 工程助手首期面向已有算例与结果：检查模型、边界条件、网格和求解设置，解释风险并提出建议；在用户要求下只修改隔离副本并展示差异；对已有结果做后处理、绘图和报告。Phase 0A 不自主启动端到端 CFD 求解、不覆盖原始算例，也不把模型建议或报告措辞当作工程判定。

会议行动助手与普通纪要润色分开：它把来源材料转成正式会议记录草稿，提取决策、共识、未决问题和具备产出、唯一负责人、期限、验收标准及验收人的责任事项；真人在末端确认，后续跟踪接收、成果提交与验收。AI 不签发正式会议记录，也不代替验收人关闭责任事项。

性能盘批处理继续作为已有工程工具链和文件产物的内部技术验收样板，并可在接入真实计算、完成工程验证后进入 Phase 0B 专业能力；它不占据 Phase 0A 三条对外类型槽。FEA、控制逻辑、FTA、P-ACE、Agent 市场、邮件自动发送和全自主 CAE 等能力本阶段冻结但不永久否决。

本 ADR 只锁定三条工作流的产品边界，不决定开发顺序，也不授权现有 L0 Agent 以生产能力名义开放。每条工作流仍需选择一个最小 tracer bullet、定义 invalid-first 验收并通过相同的授权、Sandbox、证据和交付门。
