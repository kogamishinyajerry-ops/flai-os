# M4 解锁物索取单（一页纸，可直接转发性能专业）

> 背景：FLAi-OS 平台的性能盘批量运行 Agent 已完成全部平台侧建设（上传需求
> 表格→批量运行→结果汇总→样本沉淀→人工审核放行，端到端演示可随时安排），
> 当前用确定性 mock 工具代替真实性能盘。接入真实性能盘只差以下两项输入
> （ADR-0005 立项时即约定），拿到后平台侧预计数天内完成适配。

## 需要什么

1. **一份脱敏样例输入**：真实性能盘一次典型计算所需的完整输入（Excel/文本/
   命令行参数均可），数值可脱敏替换，但**格式、字段名、单位、文件结构必须
   保真**——适配器按它写解析。
2. **入参清单**：性能盘可调输入参数的完整列表（参数名/类型/单位/合法范围/
   默认值），以及输出结果的字段说明。有现成文档复印即可，不必新写。

## 顺带想确认的（当面 10 分钟）

- 性能盘的调用形态：命令行？COM/DLL？Excel 宏？人工操作界面？
  （决定适配器形态，docs/M4_intranet_day1_recon_checklist.md ①组）
- 一次典型计算的耗时量级（秒/分钟/小时——决定平台侧超时与队列策略）；
- 内网机器的 Python 环境与安装限制（有无内部 pip 镜像）。

## 脱敏要求（我们主动承诺）

- 样例数值可全部替换为虚构值，我们只需要**结构**；
- 平台内所有涉及该工具的样本/产物将带数据分级标记，管控见平台治理文档；
- 出口管制敏感型号词一律不进平台仓库与界面（既有红线纪律）。

## 为什么现在要

平台的样本库→评测集→成熟度晋升治理链已建成并实证。真实性能盘接入后，
每一次工程师使用都会自动沉淀为可复用数据资产（任务书 §11.4 V0.3-V0.5
演进路径的数据地基）。样例输入到位越早，内网部署当天可用的把握越大。
