## 战略判断

平台本地能建的已建完（M0-M10），但三个「0」是当前全部投入的乘数瓶颈：

1. **0 个可信结论**——6 个 Agent 全 L0 全 mock/占位（agents/*/agent.yaml
   limitations 自曝），工程师第一次任务必以「原来是 demo」收场；
2. **0 个鉴权层**——WelcomeGate 是本地工作身份非认证（README 已知限制 #14），
   真数据流入后 retrofitting 成本随数据量单调上升；
3. **0 个备份策略**——治理闭环产出的证据链（samples/eval_runs/promotions）
   无任何保护。

同时 **M4 被误定性为「被动等内网」**：ADR-0005 明列的两个解锁物（脱敏样例
输入+入参清单）是可立即发起的外部协调动作，任务书 §17 时限早已超期。

## M11 立项范围（三线并进）

### Line A 诚实与信任前置（零外部依赖，立即）
- A1 composer Agent 选择器补 maturity 徽章+核心 limitation 摘要——「L0/虚构」
  不许藏在两跳深的 /portal 里（宪法第五条在最高触达面的落地）；
- A2 治理闭环首次真实实证：performance_disk_agent 评测集补到 ≥3 case 含
  失败路径 → 真跑评测全绿 → 走完整晋升门 L0→L1（M10 设施建而不用=沉没）。

### Line B M4 闸前安全批（真数据流入前必须闭合）
- B1 真鉴权最小落点：设计 ADR（本地用户表+后端 session+内网 SSO 适配缝，
  先设计后实现）→ 最小实现（登录/会话/created_by 从记名变认证）；
- B2 samples/files 数据分级标记（internal/sensitive 轴，EAR 红线的机制化
  前置——mock 期打好标记轴，真数据来了才有处可标）；
- B3 备份/恢复纪律：SQLite 在线备份脚本+恢复演练门（backup 不演练=没有备份）。

### Line C 内网 D-Day 准备（等待期变准备期）
- C1 M4 解锁物索取材料包（可直接转发部门的一页纸：要什么/为什么/脱敏要求）
  + performance_disk 真实 Adapter 接口骨架占位（对齐 mock 三件套接缝，
  显式标注占位非定案）；
- C2 轻量部署自检门 scripts/deploy_selfcheck.sh（区别于开发用 verify_all：
  免 node/免 playwright，纯运行时探针）；
- C3 离线发布包：先做「内网有无 pip 镜像」双分支预案文档，不盲做完整版。

### 明确不做（对抗裁决砍掉/时机不对）
- 零鉴权下的任务分享链接（=给 README #14 开口子）；晋升提示弹窗；部门需求
  看板（需真实用户流量）；eval 异步队列/快照句柄 API（规模前提未到）；
  真实工具 Agent 收编（L 成本，先做资产库可行性侦察再决定立项，不贸然承诺）。

### 递延（外部前提未备）
- Windows 特有分支实测（需 Windows 机器）；离线发布包完整版（待 C3 预案
  确认内网 pip 现实）；50 人规模化批（GC 执行器/观测面板/worker 吞吐——
  真实用户到来后按数据说话）。
