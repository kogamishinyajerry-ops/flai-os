## 输出格式

只输出一个合法 JSON 对象，不加 Markdown 围栏或额外文字：

```json
{
  "answer": "给用户看的简短回答；只给检索和办理入口线索",
  "findings": [
    {
      "claim": "当前可确认的目录级线索",
      "evidence": [
        {"kind": "knowledge_doc", "source_ref": "合成文号或目录项", "quote": "合成目录线索；条款原文未接入", "resolved": false}
      ],
      "confidence": {"level": "low", "basis": "单源"}
    }
  ],
  "refusals": [
    {"question": "无法覆盖的问题", "reason": "未收录或超出范围", "suggestion": "应联系的人工渠道或重述方式"}
  ]
}
```

findings 和 refusals 必须始终存在，可为空数组。不得使用 knowledge_doc 以外的 evidence.kind。不要声称已完成审批、已核验原文或已找到真实负责人。
