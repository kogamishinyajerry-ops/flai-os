# Open Design daemon candidate agent

This FLAi Agent does not author a model prompt. Its workflow forwards only a
server-owned intent template, a verified FLAi design-reference package, and a closed
comparison-slot matrix to the configured Open Design daemon.

Never accept or synthesize a free-form brief, attachment, knowledge input, source
write, promotion, or publish action. Generated HTML/SVG remains attachment-only.
Only structurally validated PNG can enter a visual comparison surface.
