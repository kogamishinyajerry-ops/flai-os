# fault_history_agent（历史故障检索）

从包内小型故障案例库检索相似历史记录，支持虚构型号 `XR-100`、`XR-300`、`巡线-7` 的同型号与跨型号对照。确定性代码先按现象标签选出候选；推理模型只能在候选 `fault_ref` 白名单内排序并生成相似依据/处置摘要，不能新增案例或改写记录。

## 产物

- `fault_history.json`：schema 校验后的 `findings`、`refusals` 与 `cross_model_matches`；
- `fault_history.md`：供审核人的可读报告；
- 成功任务仍停在 `waiting_review`，由人具名批准或拒绝。

## 能力边界

- 相似≠适用；任何跨型号匹配都只是排查参考；
- 所有处置建议必须经人签发，Agent 不确认根因、不下维修指令、不做适航或安全放行；
- 未收录型号直接返回非空 `refusals`，不会拿其他型号冒充覆盖；
- 所有 `fault_case` 依据均为 `resolved: false`；
- 模型上游空返回、截断或返回候选外编号时任务诚实失败，不伪造报告。

> **合成声明：demo 语料全合成，真实性未核。**案例库中的型号、故障编号、现象、原因、处置、标签与评测问题全部虚构，不含任何真实厂商专有内容或真实故障记录。

## 使用

任务输入：

```json
{
  "problem_description": "任务后段出现间歇断电，热浸后复现，冷却后恢复",
  "model_type": "XR-100"
}
```

`model_type` 可省略；省略时在三个合成型号中统一检索。当前检索是小型演示底座，不证明真实业务检索质量。
